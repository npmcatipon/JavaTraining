# Module 5 Activity 3

## **Objective**
You are required to create a Java application that can:
- **Add a Student**  
    - Capture student details: *name, age, email*.  
    - Store these details in a *students* table.  
  
- **Add a Course**  
	- Assign a course to a specific student.  
    - Capture *course name* and *grade*.
    - Store these details in a *courses* table.  
    - Ensure that each course is linked to a valid student.  

- **Display all Students**  
    - Show all student records with *ID, Name, Age* and *Email*.  

- **Display all Courses**  
    - Show all courses with *ID, Course Name, Grade* and the *Student Name* enrolled.  
    - **Tip:** Use *JOIN* to combine data from students and courses table.
